# example_typst

Minimal Typst starter workspace for VS Code.

## Included Files

- `main.typ`: Sample Typst document with headings, table, and math.
- `.vscode/extensions.json`: Recommended VS Code extensions.

## Recommended VS Code Extensions

- `myriad-dreamin.tinymist` for Typst language support and live preview.
- `analytic-signal.preview-pdf` to preview generated PDFs inside VS Code.

## Quick Start

1. Open `main.typ` in VS Code.
2. Install the recommended extensions when prompted.
3. Use the Typst preview command from the Command Palette:
	`Tinymist: Open Preview`

If you have the Typst CLI installed, you can also compile manually:

```bash
typst compile main.typ
```
